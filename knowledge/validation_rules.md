# 门禁校验规则库（Agent B 唯一规则源）

## 1) 调用触发条件

当任务是“对 Agent A 产物做最终门禁判断”时，必须调用本规则库。

## 2) 输入格式

输入必须满足 `contracts/handoff_schema.md` 的 `AgentAOutput`。

## 3) 输出格式

输出必须满足 `contracts/handoff_schema.md` 的 `AgentBOutput`（与输入同构）：

- `batch_id`
- `items[]`（九个基础字段）
- 不追加 `verdict`、`violations`、`repair_suggestions`

## 4) Must（必须满足）

### M01 事件类型枚举合法

- `事件类型` 仅允许：`点击`、`曝光`、`浏览`、`时长`、`其他`、`性能`。
- 枚举外值直接 `FAIL`。

### M02 页面位置合法

- `页面位置` 必须命中 `configs/enums/page_locations.json` 合法路径。
- 多页面位置必须用英文逗号 `,` 分隔，且每个值单独合法。
- 无法匹配时允许 `无页面位置`。

### M03 功能名称语义独立

- `功能名称` 必须表达业务功能，禁止承载事件类型语义。
- 禁止包含事件词：`点击/曝光/浏览/时长/性能/其他`（含中英文变体）。
- 禁止以数字开头。

### M05 中文名拼接规范

- `埋点中文名` 必须满足 `cn_name-功能名称-事件类型`。
- 多页面位置时，按 `workflows/workflow.md` 的多值规则生成 `cn_name`。

### M06 场景命中一致

- 命中 `knowledge/domain_scenarios.md` 时，输出必须与该场景归一目标一致。

### M07 描述可解释

- `埋点描述` 必须可解释“场景 + 行为 + 上报原因”。
- 禁止仅有“按钮点击/页面曝光”等无上下文描述。

### M08 道具命中一致

- 若命中 `B_items/C_items` 道具词表：
  - 页面位置优先道具相关路径
  - 功能名称保留道具语义
- 不满足则 `FAIL`。

## 5) Forbidden（绝对禁止）

### F01 功能名称包含事件词

- 命中事件词直接 `FAIL`。

### F02 虚构业务事实

- 输出中出现输入与需求文档都不存在的业务事实，直接 `FAIL`。

### F03 非枚举页面位置

- 输出枚举外页面位置，直接 `FAIL`。

### F04 中文名结构错误

- 非 `cn_name-功能名称-事件类型` 结构，或事件类型不一致，直接 `FAIL`。

### F05 场景命中后仍冲突

- 已命中高优先级场景却输出相反值，直接 `FAIL`。

### F06 多值分隔错误

- 使用中文逗号 `，`、顿号 `、` 或空格替代英文逗号 `,`，直接 `FAIL`。

### F07 命中道具却未走道具页面

- 命中道具后输出无关页面或错误降级为 `无页面位置`，直接 `FAIL`。

## 6) 结论分级

- `PASS`：无 Must/Forbidden 违规。
- `WARN`：仅建议项，不阻断。
- `FAIL`：命中任一 Must 失败或 Forbidden。

说明：分级用于 Agent B 内部校验决策，不作为主输出字段。

## 7) FAIL 时修正要求

命中 `FAIL` 时，Agent B 必须执行最小原地修正并复校。若需要保留证据，写入 sidecar，建议字段：

- `rule_id`
- `field`
- `old_value`
- `new_value`
- `reason`
